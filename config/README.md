# OpenDR Config Files

`server.toml` is a local development and demo configuration. It is generated by
setup flows and may contain inline sample credentials or relaxed controls. Do
not use it as a production starting point.

Use `production.toml` as the hardened production template and copy
`production-aci.toml` to the configured `access_control.rules_file` path before
deployment. Validate the resulting host-specific config with:

```bash
scripts/production_config_gate.sh /etc/opendr/provider/server.toml
```

Files under `config/examples/` and configs generated by demo scripts are also
non-production unless they are explicitly hardened and pass the production
config gate.
